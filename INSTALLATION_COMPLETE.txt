🔄 WORKFLOW VOORBEELD
---------------------
Scenario: Nieuwe SSL certificaat voor productie webserver

1. Voeg server toe:
   - Naam: "Production Webserver"
   - IP: 192.168.1.100
   - SSH user: root
   - Cert path: /etc/apache2/ssl

2. Genereer & installeer SSH key:
   - Klik op key icoon
   - Kopieer public key
   - ssh root@192.168.1.100
   - Plak in ~/.ssh/authorized_keys

3. Upload certificaat:
   - Klik upload icoon
   - Select .pem file (certificaat)
   - Select .key file (private key)
   - Upload

4. Deploy:
   - Klik deploy icoon (raket)
   - Bevestig
   - Wacht op success melding
   - Controleer status op dashboard

5. Monitor:
   - Dashboard toont status
   - Groen badge = geldig
   - Dagen tot expiratie zichtbaar
   - Recent logs tonen deployment
